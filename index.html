COMPLETED / VERIFIED Featured Data Pipeline

Infopark Job Web Scraper

Python • Requests • BeautifulSoup • Pandas • OpenPyXL

An automated web scraping and ETL data collection pipeline engineered in Python to extract, sanitize, and structure technical employment listings from the live Infopark Kerala web portal. It navigates multi-page table layouts, implements polite request rate-limiting to prevent server blocking, cleans and deduplicates job records using Pandas, and programmatically generates formatted, analyst-ready Excel datasets with OpenPyXL.

Implemented Source Features:

  • Multi-Page Scraping: Automatic pagination handling up to collection targets
  • Rate-Aware Crawling: Randomized request intervals (1.5s–3.0s)
  • Data Extraction: Company, Job Title, Posted Date, Deadline, URL
  • Two-Tier Deduplication: In-memory URL set and Pandas deduplication
  • OpenPyXL Formatting: Header styling, cell borders, and freeze panes (A2)
  • Spreadsheet Features: Dynamic hyperlinks and table auto-filter
  • Defensive Scripting: HTTP error catching and file-lock protection
  • Structured Dataset: Clean primary key indexing (Job ID)
