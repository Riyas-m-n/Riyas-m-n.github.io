WEB SCRAPING • DATA PIPELINE Python • Pandas • Excel Automation

Infopark Job Web Scraper

Python • Pandas • Web Scraping • OpenPyXL • MS Excel • Data Cleaning

A Python-based web scraping and data processing workflow developed to collect, clean, and structure multi-page technical job listings from the live Infopark Kerala portal. It implements request delays to handle pagination politely, performs duplicate detection and data normalization with Pandas, and generates formatted, auto-filtered Excel workbooks using OpenPyXL.

Key Technical Highlights:

  • Multi-Page Scraping: Automated pagination to collect listings across multiple pages
  • Polite Crawling: Request delays between pages to ensure respectful data collection
  • Data Extraction: Company, Job Title, Posted Date, Deadline, URL
  • Pandas Data Cleaning: Deduplication, missing-value handling, and clean indexing
  • OpenPyXL Formatting: Header styling, auto-column widths, and freeze panes
  • Spreadsheet Features: Clickable hyperlinks and table auto-filters
